## 🚀 Featured Work

### 🧬 AI-Powered Mainframe Modernization Assistant
**COBOL → Java · compiler-oriented modernization**

Translates legacy COBOL into Java through structured program analysis instead of treating source as plain text.

```text
COBOL source → Lexer → Parser → AST → Semantic validation → IR → Java codegen → javac check
```

- Lexing, parsing, AST construction, semantic validation, intermediate representation
- Java generation with control-flow translation, `CALL` / `PERFORM` handling
- Structured diagnostics, golden-output regression tests, `javac` validation, deterministic output

`Python` `FastAPI` `COBOL` `JCL` `Tree-sitter` `LangChain` `ChromaDB`

<br>
