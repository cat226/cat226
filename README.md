## Featured Work

### AI-Powered Mainframe Modernization Assistant

**COBOL → Java · Compiler-oriented modernization**

`Python` `FastAPI` `COBOL` `JCL` `Tree-sitter` `LangChain` `ChromaDB`

A structured modernization pipeline for translating legacy COBOL systems into modern Java applications.

- Lexical analysis, parsing, and AST construction
- Semantic validation and intermediate representation
- Java code generation and control-flow translation
- `CALL` / `PERFORM` handling
- Structured backend diagnostics
- Golden-output regression tests
- `javac` compilation validation
- Deterministic output testing

> Modernizing legacy systems through structured program analysis rather than treating source code as plain text.
